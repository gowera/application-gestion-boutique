# APPLICATION GESTION BOUTIQUE

CAHIER DES CHARGES POUR LE SITE CONETEC
Application web SPA de boutique en ligne et gestion commerciale
1. Présentation du projet
CONETEC est une entreprise spécialisée dans la vente de matériels, l’installation, la maintenance et les services techniques liés à l’électricité, l’énergie solaire, la sécurité, les réseaux, le froid, la climatisation, la téléphonie et l’aménagement intérieur.
L’objectif est de créer une application web moderne en SPA React, composée de deux espaces principaux :
1.	Un site public de boutique en ligne permettant aux clients de découvrir les produits et services, commander, demander un devis et contacter CONETEC.
2.	Un tableau de bord d’administration permettant de gérer l’ensemble des opérations commerciales, financières, logistiques et humaines de la boutique.
L’application doit être responsive, rapide, moderne, sécurisée et utilisable sur ordinateur, tablette et smartphone.
2. Objectifs principaux
•	Vendre des produits et services CONETEC en ligne.
•	Gérer les ventes réalisées en ligne et directement en boutique.
•	Centraliser la gestion des produits, stocks, clients, commandes, dépenses, caisse, employés, salaires et loyers.
•	Réduire les erreurs de calcul et améliorer le suivi financier.
•	Générer des rapports détaillés par période.
•	Permettre aux clients de demander une installation, un dépannage, une maintenance ou un devis.
•	Assurer une traçabilité complète de chaque mouvement important dans le système.
3. Services proposés par CONETEC
Le site public doit présenter clairement les services suivants :
•	Installation électrique : conception et pose conformes aux normes de sécurité.
•	Maintenance des équipements : diagnostic de pannes, réparation et entretien.
•	Énergie solaire renouvelable : étude, conception, installation et maintenance photovoltaïque.
•	Outils logiciels CAD : AutoCAD, SketchUp, plans et schémas techniques.
•	Vidéosurveillance CCTV : installation, configuration et gestion de caméras.
•	Contrôle d’accès : installation de systèmes d’accès sécurisés.
•	Alarmes de sécurité : détection d’intrusion et alertes.
•	Téléphonie fixe et VoIP : installation et maintenance.
•	Froid et climatisation : installation, réparation et entretien de climatiseurs et réfrigérateurs.
•	Décoration intérieure : aménagement lumineux et design.
•	Réseaux et Internet : Wi-Fi, LAN, antennes, liaisons et installations réseau.
Chaque service doit posséder une page détaillée avec description, images, avantages, formulaire de demande de devis et bouton de contact rapide.

7. Module Produits et Stock
Ce module doit gérer les produits et le stock dans un même système.
Fonctionnalités :
•	Ajouter un produit.
•	Modifier un produit.
•	Désactiver ou supprimer un produit.
•	Ajouter plusieurs images.
•	Créer des catégories et sous-catégories.
•	Ajouter une marque.
•	Ajouter un fournisseur.
•	Définir le prix d’achat et le prix de vente.
•	Définir un seuil d’alerte de stock.
•	Ajouter une référence ou un code-barres.
•	Importer des produits via fichier Excel ou CSV.
•	Exporter la liste des produits.
•	Rechercher, filtrer et trier les produits.
•	Voir l’historique de chaque produit.
•	Voir les mouvements de stock.
•	Ajouter un stock manuel.
•	Corriger un stock avec justification.
•	Gérer les produits en rupture.
•	Gérer les produits sur commande.
•	Gérer les variantes : taille, couleur, capacité, modèle, puissance ou autres caractéristiques.
Le stock doit diminuer automatiquement après :
•	Une vente en ligne confirmée.
•	Une vente directe validée.
•	Une sortie manuelle validée.
•	Une utilisation de matériel dans une intervention technique.
Le stock doit augmenter automatiquement après :
•	Un achat fournisseur validé.
•	Une entrée de stock manuelle validée.
•	Un retour client validé.

19. Gestion des rôles et sécurité
Le système doit gérer plusieurs niveaux d’accès.
Rôles principaux :
•	Administrateur : accès total.
•	Manager : gestion opérationnelle sans accès aux paramètres critiques.
•	Caissier : accès à la caisse, ventes et clients.
•	Vendeur : accès limité aux ventes et produits.
•	Technicien : accès aux interventions attribuées.
•	Comptable : accès aux dépenses, rapports, salaires et caisse.
•	Livreur : accès aux commandes à livrer.
•	Client : accès à son compte, ses commandes et ses devis.
Exigences de sécurité :
•	Authentification sécurisée.
•	Réinitialisation de mot de passe.
•	Gestion des permissions.
•	Journal d’activité.
•	Historique des modifications importantes.
•	Protection des données sensibles.
•	Validation des formulaires.
•	Sauvegardes régulières.
•	Connexion HTTPS obligatoire.
•	Politique RLS Supabase pour protéger les données par rôle.
20. Architecture technique recommandée
Frontend
•	React.
•	TypeScript.
•	Vite.
•	React Router.
•	Tailwind CSS ou autre bibliothèque UI moderne.
•	React Query ou TanStack Query.
•	Zustand ou Context API pour l’état global.
•	PWA facultative pour une meilleure utilisation sur mobile.
Backend et base de données
•	Supabase.
•	PostgreSQL.
•	Supabase Auth.
•	Supabase Storage pour les images, factures, reçus et documents.
•	Supabase Realtime pour les mises à jour de stock et commandes.
•	Edge Functions ou fonctions PostgreSQL pour les opérations sensibles.
Règles importantes
•	Les opérations de vente doivent être transactionnelles.
•	Une vente ne doit jamais être validée si le stock est insuffisant.
•	Les calculs doivent être réalisés côté base de données ou backend pour éviter les manipulations côté navigateur.
•	Les mouvements de stock doivent être enregistrés automatiquement.
•	Les données financières doivent être protégées et auditables.
•	Les anciennes migrations Supabase ne doivent jamais être modifiées après déploiement.

Le projet sera considéré comme réussi lorsque :
•	Les clients peuvent commander des produits en ligne.
•	Les employés peuvent réaliser des ventes directes.
•	Le stock diminue automatiquement après chaque vente.
•	Les achats augmentent automatiquement le stock.
•	Les crédits clients sont correctement suivis.
•	Les dépenses, loyers et salaires sont enregistrés.
•	Les rapports affichent des calculs cohérents.
•	Les administrateurs peuvent gérer les rôles et permissions.
•	Les factures et rapports peuvent être téléchargés.
•	Le site est rapide, sécurisé et adapté aux téléphones.
